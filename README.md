# BounceSMS-Client
**This is the Bounce SMS _CLIENT_ app, which should be used in conjunction with the _HOST_ app [found here](https://github.com/Vrpndt/BounceSMS-Host).**

Bounce SMS is a project that lets outdated 2G/3G Android devices (clients) send and receive SMS and MMS messages by connecting it to a modern 4G/5G-capable device (host).

The client app is written to run on **Android versions 2.1 - 2.3**, and requires Bluetooth permissions as well as full SMS permissions.
